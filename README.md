## 快速开始

```bash
# 1) 看讲义 —— 文件自带测试用例，直接跑，打印 PASS / FAIL
python LeetCode-Day01.py

# 2) 默写 —— 把当天题目写成函数，存进当天的 月.日.py（如 9.9.py）

# 3) 验收 —— 自动挑「日期最新」的练习文件来批改
python Hot100-自测批改器.py

#    也可以显式指定某一天
python Hot100-自测批改器.py 9.8.py
```

练习文件的定位优先级：**命令行指定 > `test.py` > 日期最新的 `月.日.py`**。

> ⚠️ 批改器目前只覆盖**简单档 28 题**（Day01~03 + Day04 部分）。中等档（Day04~08）的用例还没补进去，可对 `Hot100-自测批改器.py` 里的 `REGISTRY` 自行扩展。

## 学习方法

### 三遍法

1. **第 1 遍**：照着讲义的 `思路` + 图示，自己默写出可运行代码，跑通用例。
2. **第 2 遍**：盖住代码，口述/手写解法与复杂度，重点看 `面试易错点`。
3. **第 3 遍**：限时手撕（不参考任何文件），做完去 LeetCode 官网找同类题再刷一遍。

### 间隔重复复习（每天只看「昨天 + 前天」）

每天开刷前，**只回看昨天和前天刷过的天次**，不回看全部历史。

**为什么**：艾宾浩斯遗忘曲线 —— 学完 1 天内会忘掉约 50~70%，之后衰减变慢。关键不是"忘了多少"，而是**在快忘的那一刻复习一次，记忆就能撑得更久**（每次复习都把曲线重新拉平且更缓）。

反过来，**"每天回看全部"是低效的**：一个昨天刚看过、现在还记得住的题，今天再看收益接近 0，但时间成本照付。77 题全看一遍，绝大多数时间是浪费的。

**建议间隔**（随复习次数逐步拉长）：

```
1 天 → 2 天 → 4 天 → 7 天 → 15 天 → 30 天
```

对应到「按天刷」：今天回看昨天 + 前天 ≈ 覆盖 1 天和 2 天两个间隔，正好接上前两次复习。第 3 次之后就该把间隔拉到一周。

> ⚠️ **关键升级：别"重读"，要"回忆"。**
> 重读代码是最弱的学习方式 —— 眼睛会骗你，让你产生"我会了"的错觉。
> 改成这个最小动作：看到题目名 → **先在脑子里/纸上写出思路骨架**（比如"二分、比较 mid 和右端、缩区间"）→ **卡住了再看代码**。
> 这叫提取练习（Retrieval Practice），效果远好于重读，而且只多花 30 秒。骨架都写不出的题，说明该单独拎出来重做。
